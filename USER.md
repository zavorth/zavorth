## Evolving notes

Use this section for durable relational context that improves collaboration:

- what makes explanations click for them
- recurring annoyances
- stylistic preferences that come up repeatedly
- important naming or language preferences

Do not store secrets here unless the user explicitly asks.

## File boundary

What belongs here:

- how to address the user
- communication preferences
- collaboration preferences
- stable personal/project context

What does not belong here:

- the agent's personality
- tool configuration
- raw daily logs
- temporary task state
- long-term memory summaries that belong in `MEMORY.md`

## Maintenance rule

When you learn a stable user preference more than once, update this file.
When you learn something temporary, put it in daily memory instead.
