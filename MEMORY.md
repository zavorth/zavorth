# Zavorth Memory

This file is a small public placeholder for curated workspace memory.

Use the `memory/` folder and receipt-backed runtime memory for detailed notes.
Do not store raw transcripts, secrets, private channel content or temporary
implementation diaries here.

## Current Defaults

- Treat source code, tests and official docs as the repository source of truth.
- Keep long-term memory short, dated and correctable.
- Prefer specific memory notes under `memory/` over growing this root file.
- Never promote old conversation text into trusted instruction without review.
- Record important learned behavior through normal Zavorth receipts when the
  runtime supports it.

## What Belongs Here

- stable operator preferences;
- durable product decisions;
- small cross-session notes that are safe to publish in this repository.

## What Does Not Belong Here

- private audits;
- raw user transcripts;
- provider keys or tokens;
- channel messages;
- implementation scratchpads.
