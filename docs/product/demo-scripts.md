# Demo scripts (honest)

Lead with **useful work**, then **daily habit**, then **trust** (approve → receipt). Do not open with governance alone.

## Script A — 45 seconds, no credentials

1. Run `zavorth demo` or open `assets/zavorth-demo/index.html`.
2. Walk Request → Preview → Approve → Receipt.
3. Say clearly: this is the Trust Loop fixture, not a live model.

## Script B — 5–10 minutes, with provider (recommended)

### Path B1 — Non-dev (Setup → Desktop → chat)

1. Open **Zavorth Setup** and finish install/repair.
2. Open **Zavorth Desktop**; pick audience (Personal / Developer / Business).
3. Connect one provider and finish first-run.
4. Use the audience starter ask (safe/read-only).
5. Optional: ask for a change that needs approval and show the approval card + receipt.

### Path B2 — CLI operators

1. `zavorth setup` (prove one provider).
2. `zavorth start` or `zavorth open`.
3. First ask (Desktop default personal starter is safe/read-only):
   > In plain language, explain what this project does and suggest three useful things you can help me with today without changing any files.
4. Optional: ask for a change that needs approval and show the approval card + receipt.

## Script C — Optional Telegram

Same runtime on phone after channel proof. Do not claim Live without doctor/proof.
