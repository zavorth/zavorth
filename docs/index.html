How It Works

Six steps from request to receipt.

1

You speak

"Summarize my inbox and draft a reply to the last email."

2

Zavorth plans

Classifies intent, picks the right tools, and prepares the work.

3

Preview

Low-risk work runs fast. Sensitive work shows you a plan first.

4

You approve

Accept, reject, defer, or grant a scoped permission.

5

Execution

Runs only through the governed gateway. No surprises.

6

Receipt

Clear record: what happened, when, result, who approved.

Start in 30 Seconds

One command to install. Three commands to run.

npm install -g zavorth@latest
npx zavorth setup
npx zavorth start && npx zavorth open
# or just chat:
npx zavorth chat
