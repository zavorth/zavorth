# Zavorth Canonical First-Run Workspace Bootstrap Wizard

Status: decision=zavorth-first-run-workspace-bootstrap-ready

The canonical first-run profile is stored at `data/runtime/first-run/profile.json`.

Supported paths:
- `zavorth setup --dry-run`
- `zavorth setup`

The wizard records user display name, agent display name, tone, workspace root, provider status, memory mode and safety posture without storing raw secrets.
