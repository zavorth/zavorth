# Reach Fabric

Reach Fabric describes how Zavorth exposes communication and device surfaces without treating catalog presence as live proof.

## Actions

| Action id | Purpose |
| --- | --- |
| `reach.synthesize` | Generate a Tier C pack through preview, approval, and quarantine |

## Capability families

`files` | `shell` | `camera` | `screen` | `location` | `notify` | `voice` | `canvas` | `clipboard` | `device` | `browser` | `maintenance`

## Safety

1. Catalog is not live readiness.
2. Live use requires proof.
3. Sensitive capabilities stay governed.
