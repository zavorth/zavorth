# Governance

Zavorth governance coordinates autonomy levels, evaluator feedback, scheduled evaluation gates, trusted examples and progressive authorization.

The system is designed to keep risky actions explicit, evidence-backed and auditable while still allowing routine low-risk work to proceed quickly.

## Decision flow

1. Classify the action and its risk.
2. Check policy, trust and scope.
3. Request approval when required.
4. Execute through governed runtime paths.
5. Record receipts and evaluation signals.

## Runtime expectations

Governance must remain language-agnostic and provider-agnostic. Human intent should be interpreted by the model/tool contract layer, not by keyword lists.
