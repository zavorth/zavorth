# Decision Patterns

## Comparar opcoes

Use esta matriz curta:

- opcao
- beneficio
- custo
- risco
- quando escolher

## Casos comuns

- monolito enxuto vs servicos
- fila assincrona vs fluxo sincrono
- cache agressivo vs simplicidade
- banco relacional vs documento

Escolha a menor arquitetura que resolva o problema com boa margem.
