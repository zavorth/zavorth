# Spec Template

## Resumo executivo

- objetivo
- publico
- resultado esperado

## Escopo

- entra
- nao entra

## Requisitos funcionais

Escreva cada requisito com:
- identificador curto
- descricao do comportamento
- condicao de sucesso

## Requisitos nao funcionais

- desempenho
- confiabilidade
- seguranca
- usabilidade
- manutencao

## Criterios de aceite

Transforme o escopo em testes simples e observaveis.

## Riscos

- dependencia externa
- duvida de regra
- conflito de prioridade
