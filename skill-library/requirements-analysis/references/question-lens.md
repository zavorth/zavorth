# Question Lens

Use estas perguntas apenas quando forem realmente necessarias para destravar o trabalho.

- Quem usa isso?
- Qual problema concreto precisa desaparecer?
- O que seria um resultado bom o bastante?
- O que esta fora do escopo?
- Existe prazo, ferramenta ou formato obrigatorio?
- Quais erros seriam inaceitaveis?

Se a resposta nao vier, assuma o caso padrao mais plausivel e documente a suposicao.
