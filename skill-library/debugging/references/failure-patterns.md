# Failure Patterns

## Falha de configuracao

Procure:
- variavel ausente
- caminho errado
- diferenca entre ambiente local e producao

## Falha de dados

Procure:
- formato inesperado
- valor nulo
- ordem errada
- encoding

## Falha de fluxo

Procure:
- condicao invertida
- estado nao atualizado
- concorrencia
- dependencia circular

## Falha de integracao

Procure:
- contrato quebrado
- timeout
- auth
- versao incompativel
