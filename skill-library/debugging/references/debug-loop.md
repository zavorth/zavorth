# Debug Loop

## Loop curto

1. Observe
2. Isole
3. Hipotetize
4. Teste
5. Corrija
6. Valide

## Boas perguntas

- O erro e deterministico?
- Qual e o menor caso que ainda falha?
- O que mudou por ultimo?
- O comportamento errado vem de dados, fluxo, ambiente ou integracao?
- Existe um log ou teste que prove a causa?

## Sinais de bom diagnostico

- uma explicacao simples encaixa no sintoma
- a evidencia bate com a hipotese
- a correcao reduz o problema sem abrir outro
