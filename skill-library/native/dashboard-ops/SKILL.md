# Dashboard Ops

Use this native skill for dashboard/control-plane operational surfaces.

## Operating Rules

- Keep layout changes behind owner approval.
- Prefer dense, scannable cards, tables, filters, and actions.
- Separate operational status from advisory warnings.
- Surface evidence, not just labels.

## Output

Return a dashboard view model proposal with status, cards, tables, filters, and safe actions.
