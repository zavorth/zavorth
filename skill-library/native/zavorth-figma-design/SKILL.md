# Figma Design

Use this native skill when:
- The task requires operations in the 'design' domain.
- Performing actions matching: Figma file operations, component extraction, design tokens.

## Operating Rules

- Extract design tokens (colors, spacing, typography) from Figma files.
- Use component instances over direct layer manipulation.
- Export assets at multiple resolutions (1x, 2x, 3x) for responsive use.
- Maintain design system consistency across component libraries.
- Generate CSS/Tailwind code from Figma auto-layout properties.

## Output

- Design tokens, exported assets, CSS code, and component documentation.
