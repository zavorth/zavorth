# SEO Optimizer

Use this native skill when:
- The task requires operations in the 'marketing' or 'content' domain.
- Performing actions matching: keyword research, on-page optimization, meta tag writing, content structure for search, SEO audits.

## Operating Rules

- Research primary and secondary keywords using intent matching (informational, navigational, transactional).
- Map keywords to content: one primary keyword per page, 3-5 secondary keywords distributed naturally.
- Optimize title tags (50-60 chars) and meta descriptions (150-160 chars) with primary keyword near the front.
- Structure content with H1 (one, contains primary keyword), H2s (secondary keywords), H3s (long-tail).
- Ensure content satisfies search intent before optimizing for density.
- Recommended keyword density: 1-2% for primary, natural distribution for secondary.
- Include internal linking suggestions and anchor text recommendations.
- When auditing existing content: prioritize fixes by traffic impact (title > headings > body > meta).

## Output

- Keyword strategy with primary, secondary, and long-tail terms.
- Optimized title tags and meta descriptions.
- Content structure outline with heading hierarchy.
- SEO checklist with prioritized action items.
