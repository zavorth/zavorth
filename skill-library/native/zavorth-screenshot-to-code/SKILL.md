# Visual Layout Interpreter

Use this native skill when:
- The task requires operations in the 'design' domain.
- Performing actions matching: translate screenshots or ui layouts into clean, production-ready react or html components.

## Operating Rules

- Transcribe visual designs into clean semantic components.
- Avoid generic placeholders or mock data; write fully styled structures.
- Apply CSS classes or modular stylesheet rules matching original layout dimensions.

## Output

Return ready components code, associated styling sheets, and layout analysis notes.
