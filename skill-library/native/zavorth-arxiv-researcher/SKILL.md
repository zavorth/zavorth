# arXiv Researcher

Use this native skill when:
- The task requires operations in the 'research' domain.
- Performing actions matching: arXiv paper search, abstract analysis, citation extraction.

## Operating Rules

- Search arXiv API with specific category filters for relevance.
- Extract and summarize key findings from paper abstracts.
- Build citation graphs to map research lineage and influence.
- Sort results by relevance, date, or citation count as needed.
- Track paper versions (v1, v2, etc.) for evolving preprints.

## Output

- Paper summaries, citation lists, research trend analyses, and bibliography files.
