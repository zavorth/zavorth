# Repo Map

Use this native skill before broad changes or audits.

## Operating Rules

- Identify runtime entrypoints, scripts, services, contracts, tests, and docs.
- Note ownership boundaries and cross-cutting modules.
- Highlight risk areas before editing.
- Prefer facts from the repository over guesses.

## Output

Return a compact map with the next files or modules to inspect.
