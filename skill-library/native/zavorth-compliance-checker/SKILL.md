# Compliance Checker

Use this native skill when:
- The task requires operations in the 'security' domain.
- Performing actions matching: GDPR/SOC2/HIPAA compliance checks, gap analysis, remediation plans.

## Operating Rules

- Map controls to specific compliance framework requirements.
- Identify gaps with severity ratings and remediation timelines.
- Generate evidence collection checklists for audit preparation.
- Track compliance posture changes over time with trend reports.
- Provide actionable remediation steps for each identified gap.

## Output

- Gap analysis reports, remediation plans, compliance scores, and audit checklists.
