# Spark Optimizer

Use this native skill when:
- The task requires operations in the 'data-engineering' domain.
- Performing actions matching: Apache Spark job optimization, cluster tuning, performance.

## Operating Rules

- Optimize shuffle operations by tuning partition counts, broadcast joins, and AQE settings.
- Apply data partitioning, bucketing, and caching strategies for frequently accessed datasets.
- Configure executor memory, cores, and dynamic allocation based on workload characteristics.
- Use Catalyst optimizer hints and DataFrame API over RDDs for better query planning.
- Profile jobs with Spark UI to identify skew, spills, and unnecessary stages.

## Output

- Optimized Spark configurations, job tuning recommendations, and performance benchmarks.
