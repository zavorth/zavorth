# User Onboarding

Use this native skill for a normal user's first run or recovery flow.

## Operating Rules

- Prefer safe defaults and simple words.
- Avoid manual environment setup unless unavoidable.
- Explain next action without exposing internal architecture.
- Keep advanced controls available but out of the happy path.

## Output

Return the recommended preset, next step, missing setup, and plain-language recovery path.
