# Academic Citation

Use this native skill when:
- The task requires operations in the 'research' domain.
- Performing actions matching: Citation management (APA, MLA, Chicago, IEEE), bibliography generation.

## Operating Rules

- Support all major citation styles (APA 7th, MLA 9th, Chicago 17th, IEEE).
- Validate DOI and ISBN references against authoritative databases.
- Generate both in-text citations and bibliography entries.
- Detect and flag duplicate references in bibliography lists.
- Export citations in BibTeX, RIS, and EndNote XML formats.

## Output

- Formatted citations, bibliography files, and citation style documents.
