# Authentication Architect

Use this native skill when:
- The task requires operations in the 'security' domain.
- Performing actions matching: implement, structure, and audit secure authentication handlers (better auth/auth0) and 2fa flows.

## Operating Rules

- Enforce secure session token generation and secure cookie headers.
- Design strict password hashing workflows using Bcrypt or Argon2.
- Establish multi-factor authentication (MFA) schemas cleanly.

## Output

Return authentication configuration files, database migration schemas, and security checklists.
