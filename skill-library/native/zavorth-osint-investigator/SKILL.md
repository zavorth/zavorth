# OSINT Investigator

Use this native skill when:
- The task requires operations in the 'research' domain.
- Performing actions matching: Open Source Intelligence gathering, social media analysis.

## Operating Rules

- Gather intelligence from publicly available sources only, respecting legal and ethical boundaries.
- Use structured analysis frameworks (Analysis of Competing Hypotheses) for evidence evaluation.
- Cross-reference findings across multiple independent sources to establish confidence levels.
- Document all sources with timestamps, URLs, and archival references for reproducibility.
- Apply operational security practices to protect investigator identity during research.

## Output

- OSINT reports, source documentation, analysis findings, and confidence assessments.
