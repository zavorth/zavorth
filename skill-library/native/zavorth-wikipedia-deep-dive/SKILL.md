# Wikipedia Deep Dive

Use this native skill when:
- The task requires operations in the 'research' domain.
- Performing actions matching: Wikipedia research, fact verification, knowledge graph building.

## Operating Rules

- Cross-reference claims across multiple Wikipedia sources.
- Check talk pages and edit history for article reliability.
- Extract structured data from infoboxes for knowledge graphs.
- Follow citation links to verify claims against primary sources.
- Use Wikipedia categories for systematic topic exploration.

## Output

- Research summaries, fact verification reports, knowledge graphs, and source lists.
