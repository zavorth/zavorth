# Task Inbox Triager

Use this native skill when:
- The task requires operations in the 'productivity' domain.
- Performing actions matching: triage and classify incoming chat channel messages into actionable tasks.

## Operating Rules

- Classify channel messages and categorize actionable items.
- Rank items by urgency and associate to target workspaces.
- Prevent task duplication by deduplicating text content.

## Output

Return prioritized task categories, scheduling options, and clean task metadata.
