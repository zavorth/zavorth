# Presentation Builder

Use this native skill when:
- The task requires operations in the 'presentation' or 'communication' domain.
- Performing actions matching: slide decks, pitch decks, quarterly reviews, lectures, workshop materials.

## Operating Rules

- Start by defining the single core message the audience should retain.
- Structure slides following one proven arc: hook → problem → solution → proof → ask.
- Limit each slide to one idea. Use headings of 6 words or fewer.
- Write speaker notes as talking points, not scripts — conversational, timed.
- Suggest visual type per slide: chart, diagram, quote, image, comparison table.
- For pitch decks: problem (1-2 slides), solution (1), market (1), traction (1), team (1), ask (1).
- For reports: summary first, details nested, appendix at end.
- Adapt density: investor decks are sparse, internal reviews can be denser.

## Output

- Slide-by-slide outline with title, content bullets, visual suggestion, and speaker notes.
- Total slide count with estimated presentation time.
- Suggested handout or appendix for deep-dive data.
