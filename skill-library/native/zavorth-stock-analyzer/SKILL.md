# Stock Analyzer

Use this native skill when:
- The task requires operations in the 'finance' domain.
- Performing actions matching: Stock analysis, fundamentals, technical indicators, screening.

## Operating Rules

- Analyze fundamental metrics (P/E, P/B, ROE, debt-to-equity) against sector benchmarks.
- Calculate intrinsic value using DDM, Graham number, or earnings-based approaches.
- Apply technical indicators (RSI, MACD, Bollinger Bands, moving averages) for timing analysis.
- Screen stocks based on configurable criteria (market cap, sector, growth, value).
- Compare peer companies on valuation multiples, growth rates, and profitability metrics.

## Output

- Stock analysis reports, screening results, and valuation comparisons.
