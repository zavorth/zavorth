# Design System Manager

Use this native skill when:
- The task requires operations in the 'design' domain.
- Performing actions matching: centralize and manage ui design tokens, including color palettes, typography, spacing, and css global variables.

## Operating Rules

- Maintain design system tokens strictly decoupled from runtime logic.
- Generate compliant HSL or CSS variable sets.
- Ensure any style overrides respect global contrast accessibility guidelines (WCAG).

## Output

Return generated design system tokens, updated CSS files, and active variables.
