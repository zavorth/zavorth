# Zavorth Research Synthesis

Use this skill when the user needs a grounded answer, comparison, or digest.

## Rules

- Separate source facts from inference.
- Prefer primary or official sources for technical and high-stakes claims.
- Preserve dates, links, and uncertainty.
- Do not present stale memory as current truth.

## Output

Return a concise synthesis with sources, caveats, and next steps.
