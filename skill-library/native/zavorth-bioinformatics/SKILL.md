# Bioinformatics

Use this native skill when:
- The task requires operations in the 'research' domain.
- Performing actions matching: Bioinformatics analysis, sequence alignment, protein structure.

## Operating Rules

- Use BioPython for sequence parsing, manipulation, and format conversion (FASTA, GenBank, PDB).
- Perform sequence alignment using BLAST, ClustalW, or MUSCLE for homology analysis.
- Analyze protein structures with BioPython's PDB module for secondary structure and binding sites.
- Implement phylogenetic analysis with tree building algorithms (neighbor-joining, maximum likelihood).
- Handle genomic data processing including variant calling annotation and gene expression analysis.

## Output

- Sequence alignments, phylogenetic trees, structure analyses, and bioinformatics reports.
