# WhatsApp Business

Use this native skill when:
- The task requires operations in the 'channels' domain.
- Performing actions matching: WhatsApp Business API workflows and template management.

## Operating Rules

- Pre-approve message templates before sending bulk messages.
- Respect rate limits and messaging windows for outbound messages.
- Validate phone number formats (E.164) before API calls.
- Handle webhook verification and message status callbacks.
- Never store message content longer than required for processing.

## Output

- Message delivery reports, template approval status, and conversation logs.
