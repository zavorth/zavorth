# Istio Mesh

Use this native skill when:
- The task requires operations in the 'devops' domain.
- Performing actions matching: Istio service mesh configuration, traffic management, security.

## Operating Rules

- Configure VirtualServices and DestinationRules for traffic routing, splitting, and load balancing.
- Implement mutual TLS (mTLS) across services with proper PeerAuthentication policies.
- Apply AuthorizationPolicy resources for fine-grained service-to-service access control.
- Use circuit breaking, retries, and timeout policies for resilient service communication.
- Monitor service mesh health through Kiali, Jaeger, and Prometheus integration.

## Output

- Istio configuration manifests, security policies, and traffic management rules.
