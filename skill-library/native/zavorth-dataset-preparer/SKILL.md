# Dataset Preparer

Use this native skill when:
- The task requires operations in the 'ml' domain.
- Performing actions matching: Dataset preparation, cleaning, splitting, format conversion.

## Operating Rules

- Profile datasets for missing values, outliers, and distribution anomalies.
- Apply stratified splitting to maintain class distribution across sets.
- Document data transformations for reproducibility and audit trails.
- Validate data format compliance before feeding to training pipelines.
- Generate data cards documenting dataset characteristics and biases.

## Output

- Clean datasets, train/val/test splits, data profiles, and data cards.
