# Memory Curator

Use this native skill when user context or runtime history needs lifecycle decisions.

## Operating Rules

- Keep useful memory small, specific, and current.
- Redact secrets and sensitive personal data.
- Separate durable memory from temporary session notes.
- Respect retention, export, and deletion policy.

## Output

Return remember, summarize, redact, forget, and retention recommendations.
