# Model Fine-Tuner

Use this native skill when:
- The task requires operations in the 'ml' domain.
- Performing actions matching: Model fine-tuning workflows, hyperparameter optimization, training management.

## Operating Rules

- Validate training data quality and distribution before fine-tuning.
- Use learning rate scheduling with warmup for stable convergence.
- Monitor training and validation loss curves for overfitting detection.
- Save checkpoints at regular intervals for training resumption.
- Evaluate with held-out test sets independent of validation data.

## Output

- Fine-tuned models, training logs, evaluation metrics, and model cards.
