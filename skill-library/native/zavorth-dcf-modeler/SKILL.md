# DCF Modeler

Use this native skill when:
- The task requires operations in the 'finance' domain.
- Performing actions matching: Discounted Cash Flow valuation model, sensitivity analysis.

## Operating Rules

- Project free cash flows using revenue growth, margins, and capex assumptions for 5-10 years.
- Calculate WACC using CAPM with appropriate risk-free rate, equity premium, and beta.
- Apply terminal value using perpetuity growth or exit multiple methodology.
- Run sensitivity analysis on key variables (WACC, growth rate, margins) to show valuation range.
- Discount projected cash flows and terminal value to derive enterprise and equity value.

## Output

- DCF valuation models, sensitivity tables, and investment summary reports.
