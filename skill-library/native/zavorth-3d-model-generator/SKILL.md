# 3D Model Generator

Use this native skill when:
- The task requires operations in the 'media' domain.
- Performing actions matching: 3D model generation, mesh editing, rendering setup.

## Operating Rules

- Maintain clean topology with quad-dominant meshes for animation.
- Apply PBR materials with proper texture map assignments.
- Optimize polygon count for target platform requirements.
- Generate UV maps before texture painting workflows.
- Set up lighting rigs appropriate for target render engine.

## Output

- 3D model files, texture maps, render outputs, and scene configurations.
