# Resume Coach

Use this native skill when:
- The task requires operations in the 'career' or 'professional-development' domain.
- Performing actions matching: resume writing, interview preparation, career path analysis, cover letters, LinkedIn optimization.

## Operating Rules

- Quantify achievements with metrics (%, $, time saved, team size) whenever possible.
- Apply the X-Y-Z formula: accomplished [X] as measured by [Y] by doing [Z].
- Tailor resume sections to the target role's job description keywords.
- For interview prep: generate STAR-format responses (Situation, Task, Action, Result).
- Map career transitions by identifying transferable skills and gap areas.
- Keep resume to 1 page for <10 years experience, 2 pages for 10+.
- Cover letters: open with specific connection to the company, close with clear ask.

## Output

- Optimized resume with action verbs, quantified bullets, and ATS-friendly formatting.
- Interview prep sheet with likely questions and structured answers.
- Career gap analysis with upskilling recommendations.
- Tailored cover letter aligned with job description.
