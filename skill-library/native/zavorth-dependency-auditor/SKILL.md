# Dependency Auditor

Use this native skill when:
- The task requires operations in the 'security' domain.
- Performing actions matching: Supply chain security audit, license compliance, outdated dependency detection.

## Operating Rules

- Check all transitive dependencies for known vulnerabilities.
- Validate license compatibility with project license requirements.
- Flag unmaintained or abandoned packages as supply chain risks.
- Generate dependency trees for full visibility into the supply chain.
- Recommend secure alternatives for problematic dependencies.

## Output

- Dependency audit reports, license compliance matrices, and upgrade recommendations.
