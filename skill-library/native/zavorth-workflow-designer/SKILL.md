# Workflow Designer

Use this native skill when:
- The task requires operations in the 'operations' or 'productivity' domain.
- Performing actions matching: process mapping, workflow design, automation identification, SOP creation, bottleneck analysis, process optimization.

## Operating Rules

- Map the current state (AS-IS) before proposing changes (TO-BE).
- Identify manual steps that can be automated, duplicated efforts, and approval bottlenecks.
- For each process: define trigger → steps → decision points → outputs → owners.
- Prioritize automations by impact (time saved) and feasibility (complexity to implement).
- Write SOPs for the operator, not the architect: step-by-step, numbered, with expected outcomes.
- Flag single points of failure and suggest fallback paths.
- Use swimlane diagrams for cross-team processes, flowcharts for sequential logic.

## Output

- AS-IS process map with bottleneck annotations.
- TO-BE optimized workflow with automation opportunities highlighted.
- SOP document with numbered steps, owners, and expected outcomes.
- Automation recommendation ranked by ROI (impact vs effort).
