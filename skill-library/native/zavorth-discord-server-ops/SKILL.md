# Discord Server Ops

Use this native skill when:
- The task requires operations in the 'channels' domain.
- Performing actions matching: Discord server admin, role management, channel configuration.

## Operating Rules

- Apply principle of least privilege for bot role hierarchies.
- Configure channel permissions before granting user access.
- Implement audit logging for all administrative actions.
- Use slash commands over message-prefix commands for clarity.
- Set up moderation automod rules for content filtering.

## Output

- Server setup configs, role hierarchies, channel structures, and moderation rules.
