# Zavorth Data Analysis

Use this skill for data inspection, summaries, and lightweight modeling.

## Rules

- Preserve original data.
- Prefer structured parsers over ad hoc text handling.
- Report assumptions, filters, and missing values.
- Avoid leaking sensitive rows or credentials.

## Output

Return findings, method, and reproducible verification.
