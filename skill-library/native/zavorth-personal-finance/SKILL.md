# Personal Finance

Use this native skill when:
- The task requires operations in the 'finance' or 'personal' domain.
- Performing actions matching: budget creation, expense tracking, investment simulation, savings planning, financial health assessment.

## Operating Rules

- Use the 50/30/20 framework as a starting point (needs/wants/savings) unless user specifies otherwise.
- Categorize expenses into fixed (rent, subscriptions) and variable (food, entertainment).
- For investment simulations: always disclose that projections are illustrative, not guaranteed.
- Compare savings vehicles by purpose: emergency fund (6 months expenses), short-term (1-3 years), long-term (5+ years).
- When analyzing spending: identify the top 3 actionable reductions, not a list of 20.
- For budget proposals: include a buffer category (5-10%) for unexpected expenses.
- Currency-aware: confirm user's local currency and cost-of-living context before recommending amounts.

## Output

- Monthly budget breakdown with category allocations.
- Expense analysis with spending patterns and reduction opportunities.
- Investment scenario projections with assumptions clearly stated.
- Financial health scorecard (emergency fund status, debt-to-income, savings rate).
