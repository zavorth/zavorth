# Jupyter Notebook

Use this native skill when:
- The task requires operations in the 'data-science' domain.
- Performing actions matching: Jupyter notebook creation, execution, and export.

## Operating Rules

- Structure notebooks with clear markdown documentation cells.
- Use virtual environments for kernel dependency isolation.
- Include data validation steps before transformations.
- Export notebooks to HTML or PDF for shareable reports.
- Clear output cells before version control commits.

## Output

- Notebook files (.ipynb), exported reports, execution results, and visualizations.
