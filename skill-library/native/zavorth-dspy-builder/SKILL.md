# DSPy Builder

Use this native skill when:
- The task requires operations in the 'ai' domain.
- Performing actions matching: DSPy prompt programming, module optimization, compilation.

## Operating Rules

- Define DSPy signatures with clear input/output field specifications and type annotations.
- Use DSPy modules (ChainOfThought, ReAct, ProgramOfThought) for structured reasoning patterns.
- Compile modules with optimizers (BootstrapFewShot, MIPRO) using training examples.
- Evaluate compiled programs with DSPy metrics to validate performance improvements.
- Export optimized prompts and few-shot examples for production deployment.

## Output

- DSPy modules, compiled programs, optimization reports, and deployable prompt configurations.
