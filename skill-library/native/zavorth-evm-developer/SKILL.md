# EVM Developer

Use this native skill when:
- The task requires operations in the 'blockchain' domain.
- Performing actions matching: EVM smart contract development, Solidity, Hardhat, Foundry.

## Operating Rules

- Write Solidity contracts following Checks-Effects-Interactions pattern to prevent reentrancy.
- Use OpenZeppelin libraries for standard implementations (ERC20, ERC721, AccessControl).
- Prefer Foundry for testing with forge test, fuzz testing, and gas snapshotting.
- Implement proper access control, input validation, and event emission in all contracts.
- Run Slither or Mythril static analysis before deployment to catch common vulnerabilities.

## Output

- Solidity smart contracts, Foundry/Hardhat projects, test suites, and deployment scripts.
