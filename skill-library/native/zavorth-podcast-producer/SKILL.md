# Podcast Producer

Use this native skill when:
- The task requires operations in the 'media' domain.
- Performing actions matching: Podcast recording, editing, publishing, RSS feed management.

## Operating Rules

- Normalize audio levels to -16 LUFS for podcast standard loudness.
- Generate chapter markers and show notes for each episode.
- Validate RSS feed XML against podcast platform requirements.
- Embed ID3 tags and episode metadata in published audio files.
- Create episode artwork meeting platform dimension requirements.

## Output

- Edited audio files, RSS feeds, show notes, and publishing confirmations.
