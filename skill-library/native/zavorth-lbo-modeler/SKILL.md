# LBO Modeler

Use this native skill when:
- The task requires operations in the 'finance' domain.
- Performing actions matching: Leveraged Buyout model, debt structure, returns analysis.

## Operating Rules

- Build sources and uses schedule including equity, debt tranches, and transaction fees.
- Model debt paydown with cash sweeps across senior, mezzanine, and subordinated tranches.
- Project EBITDA growth, margin expansion, and working capital changes over hold period.
- CalculateIRR and MOIC for equity investors under base, upside, and downside scenarios.
- Perform credit analysis with leverage ratios, interest coverage, and debt service metrics.

## Output

- LBO models, debt schedules, returns analysis, and scenario comparisons.
