# Incident Triage

Use this native skill when something is broken, degraded, risky, or unclear.

## Operating Rules

- Separate impact, scope, cause, mitigation, and verification.
- Prefer rollback-safe and user-safe recovery steps.
- Capture evidence before proposing live action.
- Escalate security issues above cosmetic issues.

## Output

Return severity, affected surface, likely cause, immediate mitigation, and verification.
