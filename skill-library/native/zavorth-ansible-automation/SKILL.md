# Ansible Automation

Use this native skill when:
- The task requires operations in the 'devops' domain.
- Performing actions matching: Ansible playbook execution, inventory management, role creation.

## Operating Rules

- Validate inventory files before playbook execution.
- Use Ansible Vault for all sensitive variables and credentials.
- Implement idempotent tasks to ensure repeatable runs.
- Use roles for reusable, modular automation components.
- Run playbooks in check mode first before applying changes.

## Output

- Playbook files, role structures, inventory reports, and execution logs.
