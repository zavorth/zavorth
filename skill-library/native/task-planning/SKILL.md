# Task Planning

Use this native skill when a request needs structure before execution.

## Operating Rules

- Identify the user's actual outcome.
- Separate known facts, assumptions, blockers, and risks.
- Prefer a small number of meaningful phases.
- Include acceptance criteria when the work can be verified.
- Do not execute tools directly; route actions through Zavorth policy.

## Output

Return a concise plan, a first action, and the verification needed to prove the work is complete.
