# Animation Maker

Use this native skill when:
- The task requires operations in the 'media' domain.
- Performing actions matching: Animation creation, keyframe editing, export workflows.

## Operating Rules

- Use easing functions for natural motion between keyframes.
- Maintain consistent frame rates throughout animation sequences.
- Organize layers and assets with clear naming conventions.
- Export in multiple formats (MP4, GIF, WebM) based on use case.
- Preview animations at reduced resolution before final render.

## Output

- Animation files, sprite sheets, export configs, and preview renders.
