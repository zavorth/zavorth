# Patent Searcher

Use this native skill when:
- The task requires operations in the 'research' domain.
- Performing actions matching: Patent database search, prior art analysis, claim comparison.

## Operating Rules

- Search multiple patent databases (USPTO, EPO, WIPO) for completeness.
- Use IPC/CPC classification codes for targeted prior art searches.
- Analyze claim language for novelty and non-obviousness assessments.
- Track patent family relationships across jurisdictions.
- Generate claim charts comparing patent claims against products.

## Output

- Patent search results, prior art analyses, claim comparison charts, and patent family maps.
