# API Security Tester

Use this native skill when:
- The task requires operations in the 'security' domain.
- Performing actions matching: API security testing, OWASP API Top 10 checks, auth validation.

## Operating Rules

- Test against all OWASP API Security Top 10 (2023) categories.
- Validate authentication mechanisms including token expiration and refresh.
- Test for BOLA/IDOR vulnerabilities across all resource endpoints.
- Check rate limiting and throttling on sensitive API endpoints.
- Validate input sanitization and output encoding on all parameters.

## Output

- API security reports, vulnerability findings, OWASP compliance scores, and fix recommendations.
