# Prometheus Alerting

Use this native skill when:
- The task requires operations in the 'monitoring' domain.
- Performing actions matching: Prometheus alerting rules, Alertmanager, PagerDuty integration.

## Operating Rules

- Write PromQL expressions for alerting rules with appropriate thresholds and durations.
- Configure Alertmanager routing with proper grouping, inhibition, and silencing rules.
- Implement PagerDuty integration with severity-based routing and escalation policies.
- Apply recording rules for expensive queries to improve dashboard performance.
- Test alert rules with promtool to validate syntax and expected firing behavior.

## Output

- Prometheus alerting rules, Alertmanager configurations, and PagerDuty integration setups.
