# Kubernetes Orchestrator

Use this native skill when:
- The task requires operations in the 'devops' domain.
- Performing actions matching: K8s deployment, scaling, monitoring, pod management.

## Operating Rules

- Validate cluster connectivity before executing any kubectl commands.
- Apply resource limits and requests to all pod specifications.
- Use namespace isolation for multi-tenant workloads.
- Generate rollback manifests before applying production changes.
- Monitor pod health status after every scaling operation.

## Output

- Deployment manifests, scaling reports, pod status summaries, and alert configurations.
