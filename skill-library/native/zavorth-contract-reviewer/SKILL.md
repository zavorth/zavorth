# Contract Reviewer

Use this native skill when:
- The task requires operations in the 'legal' or 'business' domain.
- Performing actions matching: contract review, clause analysis, risk identification, plain-language translation, terms comparison.

## Operating Rules

- Flag high-risk clauses: unlimited liability, automatic renewal, non-compete scope, IP assignment, indemnification asymmetry.
- Translate legal jargon to plain language with the original clause referenced.
- Compare proposed terms against industry standard benchmarks when possible.
- Generate a pre-signature checklist: missing items, red flags, negotiation points.
- Identify asymmetries where one party bears disproportionate risk or obligation.
- Note any clauses that conflict with local jurisdiction or common protections.
- When no actual contract is provided, generate a clause library for the requested contract type.

## Output

- Risk-rated clause-by-clause analysis (red/yellow/green).
- Plain-language translation of complex terms.
- Pre-signature checklist with negotiation recommendations.
- Summary of obligations per party with timeline.
