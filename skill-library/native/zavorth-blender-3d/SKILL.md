# Blender 3D

Use this native skill when:
- The task requires operations in the 'creative' domain.
- Performing actions matching: Blender 3D modeling automation, scene setup, rendering.

## Operating Rules

- Use Blender's Python API (bpy) for scripted modeling, material creation, and scene setup.
- Automate render configurations including resolution, samples, engine (Cycles/EEVEE) settings.
- Implement parametric modeling with modifiers for non-destructive workflows.
- Handle UV unwrapping, texture mapping, and shader node setup through scripting.
- Batch render operations with proper output formats and compositing node configurations.

## Output

- Blender Python scripts, scene files, rendered assets, and automation pipelines.
