# Audio Editor

Use this native skill when:
- The task requires operations in the 'media' domain.
- Performing actions matching: Audio editing, mixing, noise reduction, mastering.

## Operating Rules

- Use FFmpeg or PyDub for audio manipulation (trimming, concatenation, format conversion).
- Apply noise reduction using spectral gating or adaptive filtering techniques.
- Implement multi-track mixing with proper level balancing, panning, and EQ.
- Support audio mastering operations (compression, limiting, loudness normalization).
- Generate waveform visualizations and spectral analysis for audio quality assessment.

## Output

- Processed audio files, mixing configurations, and audio analysis reports.
