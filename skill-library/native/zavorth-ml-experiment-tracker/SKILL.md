# ML Experiment Tracker

Use this native skill when:
- The task requires operations in the 'ml' domain.
- Performing actions matching: MLflow/W&B integration, experiment logging, metric comparison.

## Operating Rules

- Log all hyperparameters, metrics, and artifacts for each experiment run.
- Use consistent experiment naming conventions for easy comparison.
- Track system metrics (GPU, memory) alongside training metrics.
- Version datasets and model artifacts with experiment associations.
- Generate comparison reports across experiment runs for analysis.

## Output

- Experiment logs, comparison dashboards, metric trend reports, and artifact registries.
