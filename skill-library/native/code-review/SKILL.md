# Code Review

Use this native skill for engineering review.

## Operating Rules

- Lead with bugs, regressions, missing tests, and unsafe behavior.
- Ground findings in file paths, contracts, or observable behavior.
- Avoid unrelated refactors.
- Preserve user work and existing architecture.

## Output

Return prioritized findings, open questions, and verification gaps.
