# Figma to Code

Use this native skill when:
- The task requires operations in the 'design' domain.
- Performing actions matching: Figma design to code conversion, component extraction.

## Operating Rules

- Use Figma API to extract design tokens, component hierarchy, and style properties.
- Map Figma auto-layout to CSS Flexbox/Grid with responsive breakpoint handling.
- Convert Figma components to framework components (React, Vue, Svelte) with proper props.
- Extract design tokens (colors, typography, spacing) into CSS variables or theme objects.
- Preserve component variants and interactive states in the generated code output.

## Output

- Framework components, design token files, and style configurations.
