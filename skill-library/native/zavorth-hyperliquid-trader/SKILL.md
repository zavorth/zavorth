# Hyperliquid Trader

Use this native skill when:
- The task requires operations in the 'blockchain' domain.

## Operating Rules

- Validate wallet signatures and API authentication before submitting any trade orders.
- Implement position size limits and stop-loss orders for all trading strategies.
- Monitor order book depth and slippage before executing large market orders.
- Track funding rates and open interest for perpetual contract positions.
- Log all trade executions with timestamps, prices, and fees for audit trails.
