# Notion Coordinator

Use this native skill when:
- The task requires operations in the 'productivity' domain.
- Performing actions matching: coordinate tasks, updates, and documents with official notion workspaces.

## Operating Rules

- Connect to Notion API endpoints under authenticated access tokens.
- Map local tasks to database records mapping attributes correctly.
