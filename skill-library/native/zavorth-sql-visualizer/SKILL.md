# SQL Visualizer

Use this native skill when:
- The task requires operations in the 'data' domain.
- Performing actions matching: SQL query result visualization and chart generation.

## Operating Rules

- Optimize queries for visualization workloads with appropriate LIMIT clauses.
- Map data types to appropriate chart types automatically.
- Include axis labels, titles, and legends on all visualizations.
- Support multiple output formats (PNG, SVG, interactive HTML).
- Cache query results to avoid redundant database calls.

## Output

- Charts, visualizations, query result tables, and interactive dashboards.
