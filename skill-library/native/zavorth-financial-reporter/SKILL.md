# Financial Reporter

Use this native skill when:
- The task requires operations in the 'finance' domain.
- Performing actions matching: Financial report generation, P&L, balance sheet, cash flow.

## Operating Rules

- Generate formatted P&L statements with revenue, COGS, gross margin, and net income breakdowns.
- Build balance sheet reports with proper classification of assets, liabilities, and equity.
- Prepare cash flow statements using direct or indirect method with operating/investing/financing sections.
- Calculate key financial ratios (liquidity, solvency, efficiency, profitability) with period comparisons.
- Include YoY and QoQ variance analysis with commentary on material changes.

## Output

- Financial statements, ratio analysis reports, and variance commentary documents.
