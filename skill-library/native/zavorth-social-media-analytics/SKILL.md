# Social Media Analytics

Use this native skill when:
- The task requires operations in the 'marketing' domain.
- Performing actions matching: Social media analytics, engagement tracking, content performance.

## Operating Rules

- Aggregate metrics across platforms using consistent time windows.
- Track engagement rate, reach, impressions, and conversion metrics.
- Generate weekly and monthly trend comparison reports.
- Identify top-performing content formats and posting times.
- Respect API rate limits when pulling platform analytics data.

## Output

- Analytics dashboards, engagement reports, trend analyses, and content performance scores.
