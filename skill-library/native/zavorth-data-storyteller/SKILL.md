# Data Storyteller

Use this native skill when:
- The task requires operations in the 'data' or 'communication' domain.
- Performing actions matching: data narrative creation, insight extraction, visualization selection, executive summaries from data, anomaly detection storytelling.

## Operating Rules

- Start with the question the audience wants answered, not the data available.
- Structure narratives: headline insight → supporting evidence → implication → recommended action.
- Match visualization to data type: trends (line), comparisons (bar), proportions (pie/donut), relationships (scatter), geographic (map).
- Surface the top 3 insights first, then provide detail for those who want to dig deeper.
- Flag anomalies and outliers with context: what changed, when, and potential causes.
- For non-technical audiences: avoid jargon, lead with "so what", use analogies.
- For technical audiences: show methodology, confidence intervals, data quality notes.

## Output

- Data narrative with clear headline, key findings, and recommended actions.
- Visualization recommendations per data type with tool suggestions.
- Executive summary (1 paragraph) and detailed analysis (full report).
- Anomaly and trend annotations with contextual explanation.
