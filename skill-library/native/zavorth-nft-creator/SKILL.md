# NFT Creator

Use this native skill when:
- The task requires operations in the 'blockchain' domain.
- Performing actions matching: NFT creation, metadata generation, marketplace listing.

## Operating Rules

- Generate ERC-721 compliant metadata with required fields.
- Pin artwork to IPFS for decentralized storage permanence.
- Validate smart contract interactions before blockchain submission.
- Include proper royalty configurations in NFT metadata.
- Test minting on testnet before mainnet deployment.

## Output

- NFT metadata, IPFS CIDs, smart contract configs, and marketplace listings.
