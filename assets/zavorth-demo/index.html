GitHub, Telegram and Discord are shown as real setup paths. A connector is never marked ready from marketing copy; it needs auth, allowlist and doctor signals.

Telegram Mobile approvals and daily tasks through the same governed runtime. zavorth connectors setup telegram --apply
Discord Minimum native bot scaffold with guild, channel and owner policy. zavorth connectors setup discord --apply
